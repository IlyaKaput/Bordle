# 1. Суть проекта

Игра, напоминающая Wordle в плане того, что надо отгадывать объект по его свойствам. Угадывание необычного оружия из
Borderlands 2.

# 2. Свойства объекта:

- Редкость (уникальное белое, уникальное синее, уникальное фиолетовое, легендарное, перламутровое, радужное,
  серафимское)
- Тип (снайперская/штурмовая винтовка, дробовик, пистолет, РПГ, Пистолет-пулемет, модификатор гранат, щит)
- Локация выпадения (множество локаций в игре)
- Производитель (в игре много разных производителей предметов)
- Шанс выпадения из источника получения

Число попыток за игру не ограничено, просто показывается итоговое число после угадывания, потому что никакие аргументы,
кроме редкости и шанса выпадения не являются ВУМом, что усложнит подсказки.
В случае ошибки, если на множестве свойств введен какой-либо порядок (белое хуже синего, которое хуже легендарного),
покажется направление правильного ответа. Если порядка нет как, скажем, в локациях, будет либо красное поле, если ответ
даже не близок, либо желтое, если локация из того же дополнения. Производитель и тип в случае ошибки просто показываются
красным цветом.

# 3. Архитектура:

Для визуализации использовать библиотеку Tkinter.

### Классы:

### TriesFrame. Класс-наследник tkinter.Frame, позволяющий удобно визуализировать результаты попыток

Методы:

- static resize(picture) - возвращает картинку измененную под габариты поля вывода для изображения оружия
- add_weapon_try(self, check_results, weapon) - добавляет на экран изображение проверяемого оружия и информацию по его
  проверке
- add_weapon_picture(self, weapon, frame) - добавляет добавляет на экран изображение оружия
- add_weapon_name(self, check_results, weapon, frame) - добавляет на экран название оружия в цвете правильного или
  неправильного ответа
- add_weapon_rarity(self, check_results, weapon, frame) - добавляет на экран редкость оружия в цвете правильного ответа
  и с символом, указывающим на нахождение правильного ответа относительно данного
- add_weapon_location(self, check_results, weapon, frame) - добавляет на экран локацию добычи оружия с наибольшим
  шансом. Цвет красный, желтый или зеленый, если эта локация недостижима из локации правильного ответа, достижима или
  совпадает с ней, соответственно
- add_weapon_type(self, check_results, weapon, frame) - добавляет на экран тип оружия в красном или зеленом цвете, если
  ответ ошибочный или правильный, соответственно
- add_weapon_drop_chance(self, check_results, weapon, frame) - добавляет на экран шанс выпадения оружия из наиболее
  эффективного источника в зеленом цвете, если ответ совпал или в красном и с символом, указывающим на нахождение
  правильного ответа относительно данного

### Comparator. Класс, содержащий методы, позволяющие сравнить ответ с правильным.

Методы:

- get_integer_value_of_rarity(rarity) - возвращает число, соответствующее редкости оружия
- compare_rarity(rarity1, rarity2) - возвращает число -1, 0 или 1 в зависимости от того, правильно ли отгадана редкость
  и если нет, то в какую сторону отклонение
- compare_location(location1, dlc1, location2, dlc2) - возвращает число 0, 1 или 2 в зависимости от того, правильно ли
  отгадана локация или близки ли локации
- compare_boolean(type1, type2) - возвращает 0, если строковые значения отличаются. Иначе 1
- compare_numbers(number1, number2) - аналогично compare_rarity(), но без необходимости переводить в int
- compare_weapons(weapon1, weapon2) - выдает массив, содержащий результаты проверок всех полей оружия

### Weapon_checker. Класс, собирающий информацию по запросу и анализирующий правильность ответа.

- Поля:
-
    - chosen_weapon - оружие, избранное для игры. Строка, прочитанная из WeaponInfo.csv
-
    - weapon_info - весь WeaponInfo.csv
- Методы:
-
    - set_weapon(weapon) - установка избранного оружия
-
    - check_weapon_with_given_weapon(weapon) - возвращает результат проверки оружия с помощью Comparator.compare_weapons
-
    - find_weapon_index(weapon_name) - находит в WeaponInfo.csv индекс строки, содержащей информацию об оружии с таким
      названием
-
    - check_weapon(weapon_name) - дает более удобный способ проверить на соответствие оружия, получая на вход только
      строку названия
